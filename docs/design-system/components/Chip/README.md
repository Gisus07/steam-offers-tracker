Chips chicos para tags de un juego y para estados: Mínimo registrado, Algo distinto, Sin conexión.

## Variantes
- **Tag:** fondo `surface-raised`, texto `ink-2`, estilo `label` a 11px en mayúsculas. Hasta tres por tarjeta.
- **Mínimo registrado:** `good-soft` con texto `good` e ícono `trending-down`.
- **Algo distinto:** `info-soft` con texto `info` e ícono `compass`; marca las tarjetas de exploración.
- **Sin conexión:** `info-soft` con texto `info` e ícono `wifi-off`, con la hora de los datos ("Sin conexión · 14:20").
- La cuenta regresiva es su propio componente (CountdownChip).

## Reglas
- Alto 26px, radio `radius-pill`, ícono de 14px. Un estado siempre lleva ícono y palabra.
- Los chips no se tocan: para filtrar está FilterChip.
